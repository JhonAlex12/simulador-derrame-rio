# Simulador de derrame en un río

Simulador interactivo que calcula el volumen de una mancha de petróleo sobre un río mediante integrales dobles y el teorema de Fubini.

Proyecto de Cálculo Multivariable (5092), Ingeniería de Sistemas, Universidad Simón Bolívar, 2026.

Para usarlo, abre `index.html` en el navegador. Es un solo archivo y no necesita instalación.
